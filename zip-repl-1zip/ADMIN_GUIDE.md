## 🚪 কীভাবে লগইন করবেন

1. ব্রাউজারে যান: `…/login`
2. ইমেইল ও পাসওয়ার্ড দিন
3. **"লগইন"** বাটনে ক্লিক করুন
4. লগইনের পর হোম পেজে চলে যাবেন
5. উপরের বাম কোণে **☰** আইকনে ক্লিক করে সাইডবার খুলুন
6. সাইডবারে **"এডমিন প্যানেল"** ক্লিক করুন

---

## 🔑 পাসওয়ার্ড পরিবর্তন

1. লগইন করুন
2. ☰ সাইডবার → **পাসওয়ার্ড পরিবর্তন**
3. বর্তমান পাসওয়ার্ড ও নতুন পাসওয়ার্ড দিন
4. **সংরক্ষণ** ক্লিক করুন

---

## 🔁 পাসওয়ার্ড রিসেট (ভুলে গেলে)

1. লগইন পেজে → **"ভুলে গেছেন?"** (পরবর্তীতে যোগ হবে — আপাতত API থেকে)
2. POST `/api/auth/forgot-password` → ইমেইল
3. Response থেকে `reset_code` নিন
4. POST `/api/auth/reset-password` → `email`, `code`, `new_password`

---

## 👥 কীভাবে নতুন এডমিন তৈরি করবেন (Super Admin only)

1. এডমিন প্যানেল → **এডমিন** ট্যাব
2. নাম, ইমেইল, পাসওয়ার্ড দিন
3. পারমিশন বেছে নিন (dashboard / students / courses / content / shop / payments / design / settings)
4. **যোগ করুন**

---

## 👨‍🏫 কীভাবে শিক্ষক যোগ করবেন

1. এডমিন প্যানেল → **শিক্ষক**
2. ফর্মে শিক্ষকের তথ্য পূরণ করুন (নাম, ইমেইল, পাসওয়ার্ড, বিশেষজ্ঞতা, পরিচিতি, ছবি)
3. **যোগ করুন**

---

## 🎓 কীভাবে ছাত্র দেখবেন / এডিট করবেন

1. এডমিন প্যানেল → **স্টুডেন্ট**
2. যে কোনো রো-তে ক্লিক করুন → পপআপ খুলবে
3. সেখানে পাবেন: পূর্ণ প্রোফাইল, কোন কোর্স কিনেছে, কত খরচ করেছে, লগইন হিস্টোরি, অভিযোগ

---

## 📚 কীভাবে কোর্স যোগ / এডিট / ডিলিট করবেন

1. **এডমিন প্যানেল → কোর্স**
2. **নতুন কোর্স** ফর্মে পূরণ করুন:
   - বাংলা ও English শিরোনাম
   - বিবরণ
   - শিক্ষক, সময়কাল
   - কভার ছবি (Upload বাটন দিয়ে সরাসরি আপলোড)
   - ✅ **ফ্রি কোর্স** টিক দিলে দাম `0` হয়ে যাবে; না হলে মূল্য দিন
3. **যোগ করুন**
4. ডান পাশের তালিকায় কোর্স দেখাবে
5. ✏️ আইকন → এডিট • 🗑 আইকন → ডিলিট

### কোর্স প্রকাশ / আনপাবলিশ
- আপাতত সব কোর্স default প্রকাশিত। `is_published` ফিল্ড যোগ করা যাবে — চাইলে বলবেন।

---

## 🎬 কীভাবে ভিডিও আপলোড করবেন

1. **এডমিন প্যানেল → ভিডিও**
2. বাংলা/English শিরোনাম, বিবরণ
3. **ভিডিও URL** — YouTube লিংক (https://youtu.be/xxxxx) বা সরাসরি .mp4 লিংক
4. **থাম্বনেইল** — Upload বাটন দিয়ে আপলোড করুন
5. কোর্স যুক্ত করুন (ঐচ্ছিক)
6. **যোগ করুন**

YouTube লিংক স্বয়ংক্রিয়ভাবে embed হবে।

---

## 📄 কীভাবে PDF আপলোড করবেন

1. প্রথমে মিডিয়া লাইব্রেরিতে গিয়ে PDF আপলোড করুন (বা যেকোনো ফর্মের আপলোড বাটন দিয়ে)
2. URL কপি করুন (`/api/files/xxx`)
3. **এডমিন প্যানেল → PDF ফাইল**
4. শিরোনাম, কোর্স, file_url দিন
5. **যোগ করুন**

---

## 🕌 কীভাবে দৈনিক হাদীস যোগ করবেন

1. **এডমিন প্যানেল → দৈনিক হাদীস**
2. পূরণ করুন: শিরোনাম, আরবি মূল, বাংলা অনুবাদ, রেফারেন্স (যেমন: সহীহ বুখারী ১/১২৩), বর্ণনাকারী
3. **যোগ করুন**

---

## 💳 কীভাবে পেমেন্ট ব্যবস্থাপনা করবেন

1. **এডমিন প্যানেল → পেমেন্ট** — সব পেমেন্ট রেকর্ড দেখুন
2. **এডমিন প্যানেল → পেমেন্ট গেটওয়ে** — bKash, Nagad, Rocket, Stripe keys যোগ করুন
3. **এডমিন প্যানেল → এনরোলমেন্ট** — কে কোন কোর্স কিনেছে, মোট আয় দেখুন
4. **এডমিন প্যানেল → অর্ডার** — শপ অর্ডার ম্যানেজ করুন

---

## 🛒 কীভাবে অর্ডার ম্যানেজ করবেন

1. **এডমিন প্যানেল → অর্ডার**
2. সব অর্ডার তালিকা দেখুন
3. স্ট্যাটাস পরিবর্তন: `pending → confirmed → shipped → delivered`
4. পেমেন্ট স্ট্যাটাস: `unpaid → paid → refunded`

---

## 🖼️ কীভাবে লোগো / ব্যানার / স্লাইডার পরিবর্তন করবেন

| কী | কোথায় |
|---|---|
| **Logo** | এডমিন → **থিম ও রঙ** → primary_color পরিবর্তন (SVG লোগো auto-themed); image-based লোগো জন্য সেটিংস থেকে আপলোড |
| **হোমপেজ ব্যানার** | এডমিন → **ব্যানার** → position=home_top |
| **স্লাইডার** | এডমিন → **স্লাইডার** |
| **ওয়েলকাম পেজের পটভূমি** | এডমিন → **ওয়েলকাম পেজ** → `hero_bg_image` |

## 🏠 কীভাবে হোমপেজ পরিবর্তন করবেন

1. এডমিন → **হোমপেজ**
2. হিরো টাইটেল, সাবটাইটেল, পোস্ট সেকশন, হাদীস, ঘোষণা — সব টগল ও কাস্টমাইজ করতে পারবেন

---

## 🎉 কীভাবে ওয়েলকাম পেজ পরিবর্তন করবেন

1. এডমিন → **ওয়েলকাম পেজ**
2. মূল শিরোনাম, সাবটাইটেল, ব্যাকগ্রাউন্ড ছবি URL, আমাদের সম্পর্কে টেক্সট কাস্টমাইজ করুন

---

## 📞 যোগাযোগ তথ্য কীভাবে পরিবর্তন করবেন

1. এডমিন → **সাধারণ সেটিংস**
2. পূরণ করুন:
   - মোবাইল নম্বর
   - **WhatsApp নম্বর** (+8801711xxxxxxx)
   - ইমেইল
   - ঠিকানা
   - Facebook, YouTube
3. **সংরক্ষণ** ক্লিক করুন

ওয়েবসাইট, ওয়েলকাম পেজ ও যোগাযোগ পেজে স্বয়ংক্রিয় আপডেট হবে। মোবাইল-এ ট্যাপ করলে call/WhatsApp/email খুলবে।

## 📱 WhatsApp নম্বর কীভাবে পরিবর্তন করবেন

1. এডমিন → **সাধারণ সেটিংস** → `WhatsApp নম্বর` ফিল্ডে নাম্বার দিন (যেমন: `+8801711123456`)
2. সংরক্ষণ করুন
3. সাইটে wa.me লিংক হিসেবে দেখাবে → ক্লিক করলে WhatsApp খুলবে

## 🎨 সাইট থিম / রঙ পরিবর্তন

1. এডমিন → **থিম ও রঙ**
2. Primary (Emerald), Accent (Gold), Background, Text — color picker দিয়ে বেছে নিন
3. Heading/Body Font পরিবর্তন করুন
4. সংরক্ষণ

## 🔍 SEO সেটিংস

1. এডমিন → **SEO**
2. পূরণ করুন:

   - Meta Description
   - Keywords
   - Google Analytics ID
   - Facebook Pixel ID
   - robots.txt

2. Firebase Console থেকে API Key, Project ID, VAPID Key কপি করে এখানে দিন
3. সংরক্ষণ
   
*Push notification একটিভেশন পরবর্তী আপডেটে যোগ হবে।*
